# A little description

It is simple microkernel for MDR1206FI and ESP32-C3.

I want to improve a theory and a practice in microkernel RTOS development.

# Narrow goals

Notice:
I do not want to do that perfect - I want to get knowledge
and to make some algorithms and architecture things
which I want "just for fun" :)

1. Effective IPC(minimal of possible latency).
2. Working with data only with static methods(Ring Buffer + static memory maps maybe).
3. Working with process isolation with PMP and maybe with MPU(if I will have iron needed for that approach).
4. Maybe if I will be great student and will study perfectly discrete math, I really want to work with formal verification(and before that with specification).
I mean and some certain tools(Frama-C, Event B, Coq, Isabelle/HOL) and some basics like math.
