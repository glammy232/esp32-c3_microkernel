# ESP32-C3 Microkernel

It is simple microkernel for ESP32-C3.

The microkernel does not have specific references, or to be more precise, there are very many sources of information used in writing the microkernel.

## Goals

1. Low-latency IPC.
2. Static memory management only.
3. (Maybe) Writing the specification and formal verification of at least a small part of the microkernel.
4. Improving the theory and practice of microkernel RTOS development.
